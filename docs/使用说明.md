# 屏幕变化截屏 PPT 工具 —— 使用说明文档

> 本工具用于**持续监控电脑屏幕指定区域**，当该区域画面发生变化时**自动截图**，并将每一张截图作为单独的一页保存到 PowerPoint（`.pptx`）文件中，同时**自动去除重复画面**，帮助你把屏幕操作的每个关键步骤沉淀成可翻阅、可分享的演示文稿。

---

## 一、两种使用方式

本工具提供两种形态，推荐使用 **① 网页版**：

| 方式 | 是否需要安装 | 是否需要网络 | 系统 | 推荐度 |
|------|------------|------------|------|--------|
| ① 网页版（浏览器打开即可用） | 不需要 | 首次需联网加载组件 | Windows / Mac / Linux 均可用 | ⭐ 推荐 |
| ② 桌面 .exe 版（Windows） | 需要打包 | 不需要 | 仅 Windows | 可选 |

---

## 二、① 网页版（推荐）

### 2.1 打开方式
1. 用 **Chrome 或 Edge**（要求较新版本）打开网页版的 `.html` 文件。
2. 浏览器会提示选择要共享的内容，点击“选择屏幕 / 窗口”按钮后，**选择需要监控的整个屏幕或某个窗口**，点击“分享”。
3. 系统弹出“选择检测区域”提示后，**用鼠标在预览画面上拖拽框出要监控的区域**（松开鼠标后区域可继续调整，见 2.3），点击“② 框选检测区域”确认。

### 2.2 页面按钮说明
| 按钮 | 功能 |
|------|------|
| ① 选择屏幕/窗口 | 选择要监控的屏幕或应用窗口 |
| ② 框选检测区域 | 在画面中框定需要检测变化的区域 |
| 重置为全屏 | 将检测区域恢复为整个屏幕 |
| ▶ 开始检测 | 开始按固定间隔采样并截图 |
| ⏸ 暂停 / ▶ 继续 | 临时暂停或恢复截图（画面发生变化不丢失） |
| ■ 停止 | 结束本轮检测 |
| ⬇ 下载 PPT | 把已保存的截图导出为 `.pptx` 文件 |
| 停止时自动下载 PPT | 勾选后，点击“停止”会自动下载 PPT |

### 2.3 框选区域的调整
- 框选完成后，松开鼠标，画面会显示一个**虚线框**；此时**可拖拽虚线框四角/边缘**进行放大、缩小，或按住框内拖动整体移动位置。
- 也可以直接在下方 `X / Y / 宽 / 高` 四个输入框中输入精确数值，点击 **应用** 确认，实现精准定位。

### 2.4 三个关键参数
| 参数 | 默认值 | 作用 |
|------|-------|------|
| 采样间隔(秒) | 0.5 | 每次检测画面的时间间隔，数值越小越灵敏、截图越频繁 |
| 变化阈值 | 5 | 与上一帧画面的差异度，超过该值才视为“发生了变化”，进行截图 |
| 去重阈值 | 2.5 | 新画面与**已保存的每一页**进行相似度比对，低于该值视为“重复画面”，自动跳过，避免内容重复 |

> **提示**：把鼠标放在滑条上左右拖动，右侧数值会“实时变化”并生效；修改采样间隔后，正在运行的检测也会立即按新间隔采样。

### 2.5 说明
- 状态栏会实时显示**状态、已捕获张数、去重跳过张数、已保存页数**。
- 由于去重是“跨所有已保存页”进行的，只要画面上出现过的内容，即使短暂消失又重现，也会被识别为重复而自动忽略，从而只保留真正的新内容。
- 导出的 PPT 为标准 16:9 宽屏幻灯片，每张截图都会**等比缩放、居中、完整放入**一页工作区，不会溢出也不会变形。

## 三、② 桌面 .exe 版（Windows，可选）

> 桌面版需先在你的 Windows 电脑上**完成一次打包**生成 `.exe`，之后无需再装 Python。

### 3.1 打包前置条件
- 一台 **Windows 电脑**（网页版支持任意系统，但 `.exe` 只能在 Windows 上生成）。
- 已经安装 **Python 3.8 及以上**，且有正常的 `pip`（若用系统自带无 pip 的 Python，建议先安装官方 Python 并勾选“Add to PATH”）。

### 3.2 一键打包
1. 将项目压缩包解压到某目录。
2. 双击项目根目录下的 **`build_exe.bat`**。
3. 脚本会自动：
   - 安装依赖（`mss`、`opencv-python`、`python-pptx`、`pillow`、`pyinstaller` 等）；
   - 调用 PyInstaller 打包为单文件桌面程序；
   - 打包完成后，**生成的 `.exe` 位于项目根目录下的 `dist\ScreenCapturePPT.exe`**。
4. 双击 `dist\ScreenCapturePPT.exe` 即可使用，之后可把该 `.exe` 复制到其他 Windows 电脑单独运行（免安装 Python）。

### 3.3 桌面版界面操作（基本与网页版一致）
- 运行后会自动创建一个本地的 `.pptx` 文件用于保存截图。
- 在预览窗口上用鼠标框定检测区域（可拖动调整大小）。
- 通过 **开始 / 暂停 / 继续 / 停止** 按钮控制截图流程。
- 不同帧画面按“变化阈值”判断是否更新，按“去重阈值”与已经保存的所有页比较，重复内容自动跳过。
- 停止后，本地 PPT 文件即为最终成果，可直接打开查看。

## 四、常见问题（FAQ）

**Q1：网页版打开后点“选择屏幕”没反应？**
请使用最新版 Chrome 或 Edge；该功能依赖浏览器的屏幕共享能力，旧版浏览器可能不支持。

**Q2：为什么有些页面没有被保存？**
如果两帧画面几乎一样（差异低于“去重阈值”），会被判断为重复内容而自动跳过，这是为了去除重复页面的正常表现。需要更灵敏时，可调小“去重阈值”或“变化阈值”。

**Q3：截出来的图在 PPT 里周围有白边？**
因为每张图会按 16:9 工作区**等比缩放**（保持比例不变形）。如果监控区域不是标准的 16:9，等比后四周会有少量留白，属正常现象。

**Q4：生成的 `.exe` 在哪里？**
在项目根目录的 `dist\` 文件夹里，文件名固定为 `ScreenCapturePPT.exe`。

**Q5：桌面版打包时报 `No module named PyInstaller`？**
说明当前 Python 没有打包工具。把 `build_exe.bat` 用“记事本”打开后，直接右键“以管理员身份运行”可自动安装；若仍失败，说明该系统 Python 缺 `pip`，请安装官方 Python 后重试。
